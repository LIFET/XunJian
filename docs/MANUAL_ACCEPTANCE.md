# 寻简发布前人工验收清单

> 当前状态：尚未执行。此清单不包含 DMG、签名、公证或真实 AI 计费验证。

## 1. 首次启动与窗口

- [ ] 全新偏好启动：左侧边栏打开，右侧 Inspector 关闭。
- [ ] 两侧栏均可手动开关；缩窄、放宽窗口时不横移、闪烁或遮挡内容。
- [ ] 关闭并重开 App 后恢复“左开右关”的产品默认值。

## 2. 文件浏览与响应式布局

- [ ] 在 360、640、960、1200pt 宽度分别检查首页、所有文件、分类、设置。
- [ ] 中英文及 100%、150%、200% 字号下无截断、重叠、按钮挤扁或横向越界。
- [ ] 单击文件立即选择；双击按偏好打开或快速查看；列表/网格切换保留位置。
- [ ] 文件类型、排序、升降序、显示方式切页和重启后保持。

## 3. 拖放、Services 与菜单栏

- [ ] 文件夹拖入首页/设置可完成授权；重复或父子来源得到明确提示。
- [ ] 文件拖入分类可归类；从列表拖到 Finder/其他 App 可正常提供文件 URL。
- [ ] Finder Services 的单文件、多文件、已索引和未索引路径行为正确。
- [ ] 菜单栏搜索可输入、打开结果、显示剩余数量并唤起同一个主窗口。

## 4. 键盘与辅助功能

- [ ] Return、Space、Delete、方向键、Shift/Command 多选、复制路径均符合 Finder 习惯。
- [ ] VoiceOver 可辨认工具栏、分类图标、文件行、选中态、扫描及搜索完成状态。
- [ ] 仅用键盘可完成搜索、筛选、分类、重命名、移动和取消操作。
- [ ] 开启 Reduce Motion 后页面、侧栏、Inspector 和状态切换无非必要动画。

## 5. 扫描与大索引体验

- [ ] 扫描、重扫、暂停来源、取消扫描时界面仍可选择文件和切页。
- [ ] 隐藏文件开关快速切换无长时间冻结，最终结果与最后一次选择一致。
- [ ] 10 万文件下选择、搜索、类型筛选、排序和导出操作无明显空白帧或卡死。

## 6. 错误与恢复

- [ ] 授权失效、数据库不可用、iCloud 临时不可读时保留旧索引和人工分类。
- [ ] 错误提示有明确恢复动作；连续错误按顺序显示，不被后来的错误覆盖。
- [ ] 重命名、移动、废纸篓及撤销遇目录替换或符号链接时安全拒绝。

## 7. AI 设置与交互（用户明确确认后执行）

- [ ] API Key 与 OAuth 状态、当前模式、测试中、失败和已验证文案准确。
- [ ] Codex/Grok 登录、验证、重启恢复和退出账号均只影响寻简私有凭据。
- [ ] AI 流式回答可停止；断流同时保留部分内容并显示失败，不误报完成。
- [ ] 本项可能触发真实网络或计费，执行前必须单独确认。
