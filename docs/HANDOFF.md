# 项目交接

## 当前项目状态

寻简 0.1.5（build 6）发布候选已完成检索、扫描、AI 与交互修复，正在执行正式发布流程。

## 已完成内容

- 修复授权冲突、一级文件遗漏、隐藏/排除规则、离线删除、FSEvents 与主目录拓扑监听；失败/取消保持旧索引。
- 正文索引支持增量原子重建；预览支持跨分块匹配。全选/导出改为 ID 查询与 500 条分页。
- OAuth 重启后校验真实模型目录；AI 请求按 UTF-8 字节预算，长名称、Emoji 与大量分类安全裁剪或分批。
- 修正设置确认框、菜单栏无障碍及不可读路径规范化。
- FSEvents 现在按“来源 + 监听根”持久化安全游标，重启可补收离线变更且全盘多流互不掩盖；游标仅在数据库写入成功后提交，旧版本升级与 0 文件来源会先做一次完整补扫。
- 跨进程不再复用整机扫描断点；移除生产扫描的 10 万文件上限，扫描完成后执行 WAL checkpoint/优化，避免长期增长。
- 文件名支持中间子串及符号检索，同时避免短词误命中 `/var/folders` 等路径；批量 FTS 重建由逐条全表扫描改为临时 ID 表单次处理。
- 同一 inode 的多个硬链接分别入库，普通重命名仍保持稳定身份；过期进度回调不再让完成后的扫描横幅复活。
- 扫描横幅明确显示“本轮已扫描”，路径字号提高，避免与数据库总数混淆。
- 全盘模式不再把沙盒容器的 `Data` 目录误当作用户主目录；使用系统账户主目录生成扫描与监听范围，并在监听根变化时强制一次补偿扫描。
- 修复全盘增量链路的两个遗漏：未知普通文件的纯元数据 FSEvent 现在会补扫，文件系统根目录 `/` 不再被错误规范化为 `//`。在线新增、退出期间新增与目录移除均已用真实 Documents 文件验证。
