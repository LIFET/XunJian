## 安装

需要 macOS 14 或更高版本。Apple Silicon 包用于 M 系列芯片，Intel 包用于 Intel Mac；不确定时使用 Universal（`-macOS.dmg`）。

文件与索引保存在本机。AI 功能需要自行连接服务，只有主动使用时才发出请求。
